# 🛒 Shopping List

# Отчет по проекту Shopping List

## Общая информация

Проект представляет собой Android-приложение для создания списков покупок. Приложение написано на Kotlin с использованием современных Android-технологий.

# 1. Используемый стек технологий

## Jetpack Compose

Используется для создания интерфейса.

Почему выбрали:

* меньше кода по сравнению с XML;
* проще создавать экраны;
* удобная работа с состоянием приложения.

---

## Material 3

Используется для готовых UI-компонентов и тем приложения.

Позволяет:

* быстро создавать красивый интерфейс;
* поддерживать светлую и темную тему.

---

## Room

Используется для хранения данных на устройстве.

Почему выбрали:

* официальная библиотека Google;
* удобная работа с локальной базой данных.

---

## Koin

Используется для внедрения зависимостей (Dependency Injection).

Почему выбрали:

* простая настройка;
* меньше boilerplate-кода.

---

## Coroutines и Flow

Используются для асинхронных операций.

Например:

* загрузка данных;
* работа с базой данных;
* обновление состояния UI.

---

# 2. Архитектура проекта

В проекте используется Clean Architecture и MVI.

## Clean Architecture

Проект разделен на слои:

### Data

Работа с базой данных и источниками данных.

### Domain

Бизнес-логика и use case.

### UI (Feature)

Экраны приложения и ViewModel.

Это позволяет:

* разделять ответственность;
* упрощать поддержку проекта;
* легче добавлять новый функционал.

---

## MVI

Для экранов используется подход MVI:

* State — состояние экрана;
* Intent — действия пользователя;
* ViewModel — обработка логики.

Плюсы:

* удобное управление состоянием;
* предсказуемая работа интерфейса.

---

# 3. Принятые правила в команде

В проекте использовались следующие правила:

* разделение кода по слоям;
* отдельные feature-пакеты;
* использование ViewModel для логики;
* UI не работает напрямую с базой данных;
* использование Coroutines для асинхронности;
* единый стиль кода.

Также использовался Detekt для проверки качества кода.

## 🚀 Сборка проекта

Проект использует **Gradle Wrapper**, поэтому все команды запускаются через `./gradlew`.

### 🔧 Debug сборка

```bash
./gradlew assembleDebug
```

---

### 🚀 Release сборка

```bash
./gradlew assembleRelease
```

> ⚠️ Для release-сборки может потребоваться настройка подписи (keystore)

---

### 🏗️ Полная сборка проекта (debug и release версии)

```bash
./gradlew build
```

### 🔍 Статический анализ (Detekt)

```bash
./gradlew detekt
```

Отчёты находятся в:

```
build/reports/detekt/
```

---

### Запуск UI-тестов (нужен запущенный эмулятор)

```bash
./gradlew connectedAndroidTest
```

Предварительно необходимо создать файл develop.properties и внести в него следующее содержание:

```bash
TEST_USER_EMAIL = login
TEST_USER_PASSWORD = password
```
